# ぱかっ！ママとおなじおべんとうづくり（gf-261121-nx3）

## 起動方法
- `index.html` をそのまま開く（file:// でも Pages のサブフォルダでも動く単一ファイル。CDN・外部読み込みなし、約 0.8MB）。
- 作り直すときだけ: `npm install && node build.mjs`（`src/` と three.js を 1 ファイルにまとめる。実行時ビルドは不要）。

## お話
朝の台所で炊飯器を「ぱかっ」→ ごはん・ふりかけ・おかず5つをママとおなじに詰めて、ふたを閉めてバッグへ →
公園まで歩く（バッグを揺らせる）→ レジャーシートでふたを「ぱかっ！」、朝つめたとおり（置き場所・ふりかけの絵・揺らした分の片寄り）に出てくる →
今度はママの菜箸がまねをして同じ物を食べる → バッグからデザートのいちご → 次の朝へ（ママのふりかけの形が変わる）。

## 確認したこと（390×844 で1回通し）
- 読み込み・開始時にコンソールエラーなし。
- 台所 → 歩く → 公園 → デザート → おしまい → 次の朝（2日目）まで通して遊べた。
- 各段階で「光る物1つ＋うっすら光る行き先」が画面内に出ていること。放置で 揺れ → 菜箸のこんこん → 半透明の指のお手本 の順に強まること。
- テクスチャはすべて canvas の手続き生成、音は Web Audio 合成（外部素材・外部 AI は不使用）。

## 既知の問題
- 実機（iPhone / iPad）では未確認。音も耳では未確認（合成音の音量・音色は実機で要調整の可能性）。
- 通し確認は遅い headless 環境のため「描画を間引いてゲーム内時間を実時間で進める確認用ラッパー」で行った。製品の `index.html` そのものは起動とエラーなしの確認のみ。
- 場面を初めて開くとき、白いフェードの裏でセットを生成するので 1 秒前後かかることがある。
- 横画面は操作できるが、縦優先の構図のため物が小さめ。
- 台所のバッグの段階で、天板の手前の縁と下の扉（無地）が画面の隅に映る。
- ごはんの上に置いたおかずは、ふたを閉めている間は隠している（ふたを突き抜けて見えないため）。
- 保存は場面の切り替わり時のみ。台所の途中で再読込すると台所の最初から。
