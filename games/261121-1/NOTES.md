# ぴっ！ママとスーパーでおかいもの（gf-261121-nx1）

## 起動方法
- `index.html` をそのまま開く（file:// でも Pages のサブフォルダでも可。外部読み込みなし、約 1.0MB）。
- 作り直す時は `node build.cjs`（`src/vendor` + `src/js/*.js` + `src/assets/*.jpg` を1ファイルにまとめる）。
- 確認用: `index.html#reset`（保存を消して最初から）、`#scene=home1|shelf|register|home2`（その場面から）。

## お話
おうちのからっぽの冷蔵庫（たまご1こ・おなかがぐぅ）→ スーパーの棚から6こをかごへ → レジで1こずつ「ぴっ」してエコバッグへ、レシートを引いて切る → おうちで冷蔵庫にしまい、扉を閉めるとママの手がレシートを貼って夕方の光で終わり。エコバッグにさわると次のおかいもの（冷蔵庫の中身は残る）。

## 確認したこと（390×844、ヘッドレス Chromium）
- 読み込み・開始・最初のタッチでコンソールエラーなし。
- お話を最初から最後まで1回通した（指の操作を合成）。各段階で「次にさわる物」が光り、放置で揺れ・ママの指さし → 半透明の手のお手本が出ることを画面で確認。
- 「ぴっ」は品物をガラスに重ねた時に1回だけ鳴り、画面にその品物の絵が出る。

## 既知の問題
- 実機（iPhone / iPad）では未確認。音は耳で聞いていない（すべて合成音）。
- 棚の場面は描画が重め（描画呼び出し約290、止まっている間は影を描き直さないので約220）。45fps を切ると解像度が自動で下がる。
- 横向きでは左右に壁と床が広く見えるだけで、構図は縦向き優先。
- 1回の買い物（6こ）では冷蔵庫は半分ほど。2回目で満杯になり、3回目以降は古い物から入れ替わる。
- 画像生成 API は使っていない（質感はすべてキャンバスで自作）。

## 描画の軽量化（iPhone / iPad 向け）
- 影は「影を落とす物・光」が動いた時だけ描き直す（`06-core.js` の renderScene）。止まっている間の描画呼び出し: 棚 289→224、レジ 128→78、おうち 65→43 / 129→78。見た目は同じ（画像比較で一致）。
- 画素数の上限 300 万（iPhone は 2 倍のまま。大きな iPad だけ少し下げる）。
- 負荷調整の目標を 60fps に（平均 45fps 未満で解像度を下げ、55fps 以上が続けば戻す）。
- 場面に入る暗転中に、まだ見えていない物の素材も先に組み立てる（途中で出た瞬間の引っかかりを防ぐ）。

## 初回起動を速く（読み込みの順番）
- **すぐ見える絵**: HTML の頭に、最初の場面（台所）を小さく写した絵 `src/assets/poster.jpg`（約 2KB）をぼかして置いた。本体のスクリプトが届く前から台所がぼんやり見え、3D の最初の数コマを描き終えたら、その絵から直接 3D の場面へ溶ける（暗い画面を待たない）。おうちから始まる時だけ（棚・レジから再開する時は従来どおり暗転から）。作り直しは `node tools/poster.cjs` → `node build.cjs`。
- **three を使う物だけに**: `src/vendor/three.bundle.js` を、ゲームで使う部品だけの版に替えた（767KB → 606KB、gzip 197KB → 153KB）。中身は同じ three r187。入口は `tools/three.entry.js`（新しく `THREE.○○` を使う時は名前を足して作り直す。手順はファイルの頭）。
- **最初はおうちのコードだけ動かす**: 棚・レジのコード（`30-shelf.js` `40-register.js`）は `<script type="text/plain" id="later">` に入れておき、起動時には動かさない。`90-main.js` はそれを待たずに `G.start()` する。棚・レジから再開する時や、準備より先に棚へ行った時は、その場で読む（`G.loadLater`）。
- **遊んでいる間に裏で用意**（`G.prep` / `G.prepScene`、`06-core.js`）: 最初の場面が出て 1 秒たったら、指が離れている間だけ1つずつ進める（さわっている間・離して 0.8 秒・場面切り替え中は待つ。その重いコマは負荷調整の計測に入れない）。順番: 棚・レジのコード → 品物 12 種の形 → お手本の手 → おうちに出る品物と手の計算式（シェーダー）→ 棚の場面の組み立て＋計算式＋画像の転送 → レジも同じ → レジ画面・レシート用の品物の絵 12 種。
- 結果（390×844、ヘッドレス Chromium・ソフトウェア描画）: 場面に入る時の暗転が 棚 13.1→7.5 秒、レジ 11.0→7.0 秒、おうち(2) 5.5→4.3 秒（このソフトウェア描画では暗転の最低時間が約 6 秒。実機では差がもっと短い時間で出る）。レジに入る時に品物の絵を6枚その場で作っていた待ちが無くなった。見た目は変更前と画像比較で同じ（違いは光の脈打ちの時刻だけ）。
